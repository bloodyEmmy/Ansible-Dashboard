# Ansible Audit Dashboard

Проект представляет собой инструмент аудита для мониторинга запусков сценариев конфигурации (Ansible Playbooks). Сервис считывает данные из базы SQLite и предоставляет как графический веб-интерфейс для пользователей, так и REST API для интеграции со сторонними системами. Разработано и протестировано для работы в среде WSL/Linux.

## Структура проекта
* `app.py` - основной файл веб-сервера (Flask).
* `database.py` - логика взаимодействия с SQLite.
* `mock_data.py` - скрипт генерации истории прокаток.
* `generate_playbooks.py` - скрипт генерации файлов сценариев.
* `playbooks/` - директория с исходным кодом Ansible сценариев.
* `templates/` и `static/` - файлы пользовательского веб-интерфейса.

## Подготовка и запуск

1. Установка зависимостей:
   pip install Flask Werkzeug

2. Генерация сценариев и тестовой базы данных:
   python generate_playbooks.py
   python mock_data.py

3. Запуск сервера:
   python app.py

После запуска веб-интерфейс будет доступен по адресу: http://127.0.0.1:5000

## Работа с API через cURL

Сервер предоставляет конечные точки для получения данных в формате JSON. Для форматированного вывода рекомендуется использовать пайплайн с утилитой `jq`.

Получить всю историю запусков:
curl -s "http://127.0.0.1:5000/api/history" | jq

Отфильтровать запуски конкретного пользователя:
curl -s "http://127.0.0.1:5000/api/history?user=v.proskuryakov" | jq

Отфильтровать по названию сценария:
curl -s "http://127.0.0.1:5000/api/history?playbook=02_docker_stack.yml" | jq

Комбинированный поиск по пользователю и дате (кавычки обязательны):
curl -s "http://127.0.0.1:5000/api/history?user=gitlab-runner&start_date=2026-05-01&end_date=2026-06-30" | jq

Прочитать исходный код конкретного сценария:
curl -s "http://127.0.0.1:5000/api/playbook/05_secure_ssh.yml" | jq
